# FMCG Sales Analysis Chatbot
A Streamlit-powered chatbot that analyzes FMCG retail sales data using Google Gemini Pro, LangChain, and SQL. Users can upload a CSV, and ask natural language questions like:

- "What were the top 5 products by revenue last year?"
- "Which store had the highest sales last quarter?"
- "Which product category sold the most in Mumbai?"

# Features
-  Upload your own sales CSV file
- Data is stored in a local SQLite database
- Powered by Gemini (Google Generative AI) for natural answers
-  Uses LangChain SQLDatabaseChain to auto-generate SQL queries
-  Clean Streamlit UI
- Returns human-friendly, non-technical insights

# Tech Stack
- Streamlit

- LangChain

- Google Generative AI (Gemini)

- SQLite

- Pandas
